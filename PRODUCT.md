# Product

## Register

brand

## Users

Thinkers, planners, students, and collaborators — people who need to
externalize ideas and see relationships. Solo users building personal
knowledge maps. Teams co-editing shared maps with realtime cursors and
comments. Voice-first users who want to build and navigate maps hands-free
via the Squishy agent.

Primary context: at a desk with a keyboard for creation, but able to
drive the canvas by voice when their hands are busy or they want to think
out loud.

## Product Purpose

SquishyMind is a mind-mapping editor where the interface gets out of the
way so ideas can connect. Five views of the same data (Canvas, Tree,
Outline, Table, Gallery), AI-powered node expansion, and a voice agent
(Squishy) that can literally build the map for you. Success is when
someone opens a blank map, talks through their thinking, and walks away
with a structured artefact they didn't know they could make.

## Brand Personality

**Bold, weird, delightful.**

SquishyMind doesn't take itself seriously. The voice agent flirts. Nodes
wobble. Confetti fires when you finish a task. The brand voice is warm
and playful, never corporate. The tagline "Your brain, but squishier"
sets the tone: smart tools, soft edges, zero pretension.

Emotional goals: surprise, play, creative confidence. Users should feel
like they're collaborating with a clever friend, not operating software.

## Anti-references

- **Notion** — clean but cold. SquishyMind is warmer, weirder, more
  personality-driven. No gray-on-gray minimalism.
- **Miro** — enterprise whiteboard energy. Too serious, too many panels,
  too "team productivity platform." SquishyMind is a tool for one brain
  first, group brains second.
- **Typical SaaS landing pages** — gradient heroes, metric grids,
  eyebrow kickers above every section. No "Streamline your workflow"
  energy.
- **Corporate mind-mapping tools** — MindMeister, XMind. Beige,
  professional, forgettable. SquishyMind is memorable.

## Design Principles

1. **Voice is a first-class input.** Squishy isn't a bolt-on widget —
   she can create, edit, move, delete, theme, and navigate the canvas.
   Every feature ships with a voice pathway.

2. **Personality over professionalism.** The interface should feel like
   a place, not a tool. Wobbly nodes, playful microcopy, sound effects,
   custom colours. If Notion would ship it, we make it weirder.

3. **Same data, many views.** Canvas, Tree, Outline, Table, and Gallery
   are transformations of the same graph. Switching views shouldn't feel
   like switching tools — it should feel like turning the same object in
   your hands.

4. **Collaboration is ambient, not administrative.** Real-time cursors,
   live reactions, dot-voting, comments — collaboration features should
   feel like people in the room, not project management overhead.

5. **Finish the thought.** The product should help users get from fuzzy
   idea to structured output. AI expand, find-gaps, make-plan, and
   presentation mode all push toward completion, not infinite editing.

## Accessibility & Inclusion

- WCAG 2.1 AA as the baseline
- `prefers-reduced-motion` respected throughout — animations have
  reduced-motion fallbacks
- Voice agent provides an alternative input mode for users who can't or
  prefer not to use keyboard/mouse
- Colour is never the sole indicator of state (flow arrows use shape and
  animation, not just colour)
